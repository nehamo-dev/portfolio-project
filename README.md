# neha-portfolio

Personal portfolio site for Neha M — built with plain HTML and CSS, no frameworks.

## Pages

- **Home** — hero and links to the three main sections
- **Building** — coming soon
- **Writing** — intro and link to [First Principles on Substack](https://nehamo.substack.com/)
- **Coaching** — intro and link to [intro.co/nehamonga](https://intro.co/nehamonga)
- **About** — background and bio
- **Contact** — email

## Stack

- Static HTML files
- Shared `style.css`
- [Inter](https://fonts.google.com/specimen/Inter) via Google Fonts
- No build step, no dependencies

## Running locally

Open any `.html` file directly in a browser, or serve with any static file server:

```bash
npx serve .
```
